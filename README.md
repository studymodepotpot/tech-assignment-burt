# Technical Assignment: Testing [Simple Calculator](https://testpages.eviltester.com/styled/calculator/)

### Tech Stack:
* Playwright
* Typescript
* Node.js

### Getting Started
To be able to execute the test scripts, you need to setup the following on your machine:
* Install VS Code (recommended IDE)
* Clone this repository
* Install Node.js (follow the steps [here](https://nodejs.org/en))
* Setup Playwright (follow the steps [here](https://playwright.dev/), select Typescript during `npm init`)
* ...and you're ready to go!
